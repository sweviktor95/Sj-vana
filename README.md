# Sjövana

Lär dig och öva båt- och fartygsintyg i webbläsaren: förarintyg, kustskepparintyg, radarintyg, mörkernavigering, SRC, LRC, ICC och fartygsbefäl klass VIII.

**Öppna:** https://sweviktor95.github.io/sj-vana/

- Kurser med lektioner och kontrollfrågor som följer NFB:s kunskapsfordringar.
- Simulatorer: sjökortsövningar, rita väjning, väjning från ratten, radarplott, dag- och nattpraktik, lanternor och fyrkaraktärer.
- Provläge med samma delar och godkäntgränser som NFB:s prov.
- Spara på hemskärmen: iPhone: Dela → "Lägg till på hemskärmen". Android: menyn → "Installera app" eller "Lägg till på startskärmen".
- Fungerar offline efter första besöket. Framsteg sparas i webbläsaren.

Övningsmaterial. Kontrollera alltid aktuella krav hos NFB och Transportstyrelsen. Övningskortet Sjövik är fiktivt och får inte användas för navigering.
